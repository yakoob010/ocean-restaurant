# 🏨 Ocean View Resort Reservation System

A comprehensive hotel reservation management system built with Java, JSP, and MySQL. This system provides complete reservation management, billing, and reporting capabilities for hotel operations.

## 🌟 Features

- **🔐 Secure Authentication** - Login/logout with session management
- **📝 Complete Reservation Management** - Create, view, and manage guest reservations
- **💰 Automated Billing** - Calculate costs with 15% luxury tax
- **📊 Advanced Reporting** - Revenue analysis and occupancy statistics
- **✅ Input Validation** - Comprehensive form validation and error handling
- **📱 Responsive Design** - Modern UI that works on all devices
- **📚 Help Documentation** - Complete user guide and system documentation

## 🛠️ Technology Stack

- **Backend**: Java 8, Servlet API, JSP
- **Database**: MySQL 8.0
- **Build Tool**: Maven 3.6+
- **Application Server**: Apache Tomcat 9.0+
- **Frontend**: HTML5, CSS3, JavaScript
- **Architecture**: MVC Pattern
